# 09 - Further Learning Resources (拓展学习资源)

## Introduction (引言)
This section provides a list of resources to continue your learning journey in the areas covered by this tutorial series.
本节提供了一系列资源，以帮助你继续学习本教程系列所涵盖的领域。
The world of computer science, programming, and simulation is vast and constantly evolving. We encourage you to explore these resources and keep learning!
计算机科学、编程和模拟的世界广阔无垠且不断发展。我们鼓励你探索这些资源并持续学习！

## General Computer Science & Programming (通用计算机科学与编程)

### Websites (网站)
*   **freeCodeCamp:** Interactive learning for web development, algorithms, data structures, and more.
    **freeCodeCamp:** 提供网页开发、算法、数据结构等方面的交互式学习。
    [`https://www.freecodecamp.org/`](https://www.freecodecamp.org/)
*   **Khan Academy (Computing):** Offers introductory courses on computer science and programming basics.
    **Khan Academy (计算机):** 提供计算机科学和编程基础的入门课程。
    [`https://www.khanacademy.org/computing`](https://www.khanacademy.org/computing)
*   **W3Schools:** Tutorials for web technologies, Python, SQL, Java, C++, and many other programming languages.
    **W3Schools:** 提供网页技术、Python、SQL、Java、C++ 以及许多其他编程语言的教程。
    [`https://www.w3schools.com/`](https://www.w3schools.com/)

### Online Courses Platforms (在线课程平台)
*   **Coursera:** Offers a wide range of courses from universities and companies. Search for topics like "Python programming," "Data Structures and Algorithms," or "Introduction to Computer Science."
    **Coursera:** 提供来自大学和公司的各种课程。可以搜索诸如“Python编程”、“数据结构与算法”或“计算机科学导论”等主题。
    [`https://www.coursera.org/`](https://www.coursera.org/)
*   **edX:** Similar to Coursera, providing access to university-level courses in various fields, including computer science.
    **edX:** 与 Coursera 类似，提供包括计算机科学在内的各个领域的大学水平课程。
    [`https://www.edx.org/`](https://www.edx.org/)

## Python Programming (Python 编程)

### Official Documentation (官方文档)
*   **The Python Tutorial:** The official, comprehensive tutorial from the creators of Python. An excellent starting point.
    **Python 官方教程:** Python 创造者提供的官方综合教程。一个极好的起点。
    [`https://docs.python.org/3/tutorial/`](https://docs.python.org/3/tutorial/)

### Websites for Practice (练习网站)
*   **HackerRank (Python Domain):** Coding challenges and competitions to hone your Python skills.
    **HackerRank (Python 领域):** 提供编码挑战和竞赛，以磨练你的 Python 技能。
    [`https://www.hackerrank.com/domains/python`](https://www.hackerrank.com/domains/python)
*   **LeetCode (Python Problems):** Popular platform for practicing coding problems, often used for interview preparation.
    **LeetCode (Python 题目):** 练习编码问题的热门平台，常用于面试准备。
    [`https://leetcode.com/problemset/python/`](https://leetcode.com/problemset/python/)

### Books (书籍)
*   Look for well-regarded beginner Python books or books focused on specific applications like "Python for Data Analysis."
    寻找广受好评的 Python 入门书籍或专注于特定应用的书籍，例如“Python 数据分析”。
*   Examples often recommended include "Python Crash Course" by Eric Matthes or "Automate the Boring Stuff with Python" by Al Sweigart.
    经常被推荐的例子包括 Eric Matthes 的《Python编程快速上手》或 Al Sweigart 的《Python编程快速上手——让繁琐工作自动化》。

## Linux & Command Line (Linux 与命令行)

### Websites (网站)
*   **Linux Journey:** A website offering easy-to-follow, step-by-step lessons to learn Linux.
    **Linux Journey:** 提供易于遵循的、分步式的 Linux 学习课程的网站。
    [`https://linuxjourney.com/`](https://linuxjourney.com/)
*   **explainshell.com:** An interactive site where you can type in a shell command and see a breakdown of each part's meaning.
    **explainshell.com:** 一个交互式网站，你可以在其中输入一个 shell 命令，并查看每个部分的含义解释。
    [`https://explainshell.com/`](https://explainshell.com/)

### Books (书籍)
*   **"The Linux Command Line" by William Shotts:** A comprehensive book that is also available for free online from the author.
    **《Linux命令行》作者 William Shotts:** 一本内容全面的书籍，作者也提供了免费的在线版本。
    (Search for "The Linux Command Line William Shotts PDF" - 搜索 "The Linux Command Line William Shotts PDF")

### General MD / Visualization (通用 MD / 可视化)
*   **MDAnalysis:** A Python library for the analysis of molecular dynamics trajectories.
    **MDAnalysis:** 用于分析分子动力学轨迹的 Python 库。
    [`https://www.mdanalysis.org/`](https://www.mdanalysis.org/)
*   **OVITO (Open Visualization Tool):** Powerful software for visualization and analysis of atomistic and particle simulation data.
    **OVITO (开放可视化工具):** 用于原子和粒子模拟数据的可视化和分析的强大软件。
    [`https://www.ovito.org/`](https://www.ovito.org/)
*   **VMD (Visual Molecular Dynamics):** A molecular visualization program for displaying, animating, and analyzing large biomolecular systems using 3-D graphics and built-in scripting.
    **VMD (可视化分子动力学):** 一个分子可视化程序，用于使用三维图形和内置脚本显示、动画化和分析大型生物分子系统。
    [`https://www.ks.uiuc.edu/Research/vmd/`](https://www.ks.uiuc.edu/Research/vmd/)
